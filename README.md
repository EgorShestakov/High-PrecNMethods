## Описание лабораторных работ

### Лаба 1. Методы Эйлера и Хойна

**Цель:** решение задачи Коши для системы ОДУ одношаговыми методами.

**Задача:**

```
x' = f_1(t, y),    x(t_0) = x_0
y' = f_2(t, x),    y(t_0) = y_0
```

**Формулы:**

Метод Эйлера (1-й порядок):

```
x_{n+1} = x_n + h · f_1(t_n, y_n)
y_{n+1} = y_n + h · f_2(t_n, x_n)
```

Метод Хойна (2-й порядок), для системы — векторный предиктор:

```
x* = x_n + h · f_1(t_n, y_n)
y* = y_n + h · f_2(t_n, x_n)

x_{n+1} = x_n + h/2 · [f_1(t_n, y_n) + f_1(t_n + h, y*)]
y_{n+1} = y_n + h/2 · [f_2(t_n, x_n) + f_2(t_n + h, x*)]
```

**Что делает `tasks_solution.py`:**

- Решает систему на отрезке `[0, 2]` с шагами `h = 0.1, 0.01, 0.001`.
- Сравнивает с точным решением.
- Выводит таблицы значений и погрешностей.
- Строит графики.

### Лаба 2. Таблица начальных значений (ряды Маклорена)

**Цель:** построение пяти начальных значений для многошаговых методов через разложение решения в ряд Маклорена.

**Идея:** для многошаговых методов (Адамс-Бэшфорт, Адамс-Мултон) нужны не только начальные условия, но и значения решения в нескольких первых точках. Они строятся через ряд Тейлора (Маклорена, если `t_0 = 0`):

```
x(t) = Σ_{k=0}^{n} x^(k)(0) / k! · t^k
y(t) = Σ_{k=0}^{n} y^(k)(0) / k! · t^k
```

Производные высших порядков находятся последовательным дифференцированием системы:

```
x'' = d/dt f_1(t, x, y)
x''' = d/dt x''
...
```

**Ключевой момент:** ряд строится один раз, от `h` не зависит. От `h` зависит только сетка, на которой вычисляются значения. Поэтому погрешность `δ(h) ~ h^(n+1)` — уменьшается при уменьшении `h` не потому что ряд «лучше», а потому что область сравнения сжимается.

**Что делает `tasks_solution.py`:**

- Строит ряды Маклорена для системы и для ОДУ 2-го порядка.
- Выводит ряды, значения производных в `t_0`.
- Заполняет таблицы пяти начальных значений для `h = 0.1, 0.01, 0.001`.
- Оценивает погрешность и порядок сходимости.

### Лаба 3. Метод Адамса-Бэшфорта

**Цель:** решение задачи Коши явным многошаговым методом.

**Формулы:**

2-й порядок:

```
y_{n+1} = y_n + h/2 · [3 f_n − f_{n−1}]
```

3-й порядок:

```
y_{n+1} = y_n + h/12 · [23 f_n − 16 f_{n−1} + 5 f_{n−2}]
```

4-й порядок:

```
y_{n+1} = y_n + h/24 · [55 f_n − 59 f_{n−1} + 37 f_{n−2} − 9 f_{n−3}]
```

5-й порядок:

```
y_{n+1} = y_n + h/720 · [1901 f_n − 2774 f_{n−1} + 2616 f_{n−2} − 1274 f_{n−3} + 251 f_{n−4}]
```

**Стартовые значения** берутся из лабы 2 (ряд Маклорена).

### Лаба 4. Метод Адамса-Мултона

**Цель:** решение задачи Коши неявным многошаговым методом с прогнозом и коррекцией (PEC).

**Формулы:**

3-й порядок:

```
y_{n+1} = y_n + h/12 · [5 f_{n+1} + 8 f_n − f_{n−1}]
```

4-й порядок:

```
y_{n+1} = y_n + h/24 · [9 f_{n+1} + 19 f_n − 5 f_{n−1} + f_{n−2}]
```

5-й порядок:

```
y_{n+1} = y_n + h/720 · [251 f_{n+1} + 646 f_n − 264 f_{n−1} + 106 f_{n−2} − 19 f_{n−3}]
```

**Алгоритм PEC:**

1. **P (Predictor):** вычислить `y_{n+1}^(P)` методом Адамса-Бэшфорта.
2. **E (Evaluation):** вычислить `f_{n+1}^(P) = f(t_{n+1}, y_{n+1}^(P))`.
3. **C (Corrector):** вычислить `y_{n+1}` методом Адамса-Мултона.

### Лаба 5. Устойчивость и сходимость

**Цель:** исследование устойчивости и сходимости многошаговых методов, оценка локальных и глобальных погрешностей дискретизации.

**Теория:**

Метод называется согласованным, если:

```
Σ α_i = 0,    Σ β_i = 1
```

Метод называется устойчивым, если все корни характеристического уравнения

```
Σ α_i q^i = 0
```

лежат внутри единичного круга `|q| < 1`, кроме одного простого корня на единичной окружности.

**Согласованный + устойчивый = сходящийся.**

**Оценка погрешности методом экстраполяции (Рунге):**

```
Δy_n = [y_n(h) − y_{2n}(h/2)] / (2^p − 1)
```

**Вложенный метод:** на каждом шаге интегрирование выполняется дважды — методом порядка `p` и `p+1`. Разность даёт оценку погрешности.

## Математическая справка

### Задача Коши

Дана система ОДУ первого порядка:

```
y' = f(t, y),    y(t_0) = y_0
```

где `y ∈ R^n`, `f: R × R^n → R^n`. Требуется найти `y(t)` на отрезке `[t_0, t_end]`.

### Одношаговые методы

Значение `y_{n+1}` зависит только от `y_n` и информации в точке `t_n`. Примеры: Эйлер, Рунге-Кутта, Хойн.

Общая формула:

```
y_{n+1} = y_n + h · Φ(t_n, y_n, h)
```

где `Φ` — функция приращения.

### Многошаговые методы

Значение `y_{n+1}` зависит от нескольких предыдущих значений: `y_n, y_{n−1}, ..., y_{n−k}`. Примеры: Адамс-Бэшфорт (явный), Адамс-Мултон (неявный).

Общая формула:

```
Σ_{i=0}^{k} α_i y_{n+i} = h · Σ_{i=0}^{l} β_i f_{n+i}
```

### Порядок сходимости

Метод имеет порядок `p`, если глобальная погрешность:

```
||y(t_n) − y_n|| = O(h^p)
```

При уменьшении `h` в 10 раз погрешность уменьшается в `10^p` раз.

### Ряд Тейлора (Маклорена)

Для решения `y(t)` в окрестности `t_0`:

```
y(t) = Σ_{k=0}^{∞} y^(k)(t_0) / k! · (t − t_0)^k
```

При `t_0 = 0` — ряд Маклорена:

```
y(t) = Σ_{k=0}^{∞} y^(k)(0) / k! · t^k
```

**Локальность:** ряд хорошо приближает решение вблизи `t_0`. Ошибка в точке `t`:

```
|y(t) − y_n(t)| ~ C · |t − t_0|^(n+1)
```

Чем дальше от `t_0`, тем больше ошибка. Поэтому при уменьшении `h` (и сжатии сетки) погрешность падает как `h^(n+1)`.

## Пример решения

Рассмотрим систему:

```
x' = e^(3t) − y,    x(0) = 1
y' = 2e^(3t) − x,   y(0) = 0
```

Точное решение:

```
x(t) = 3/4 · e^t + 1/8 · e^(−t) + 1/8 · e^(3t)
y(t) = −3/4 · e^t + 1/8 · e^(−t) + 5/8 · e^(3t)
```

Ряды Маклорена (до `t^5`):

```
x(t) = 1 + t + t^2 + 2/3 · t^3 + 11/24 · t^4 + 31/120 · t^5
y(t) = t + 5/2 · t^2 + 8/3 · t^3 + 25/12 · t^4 + 151/120 · t^5
```

Значения производных в `t_0 = 0`:

```
x^(0)(0) = 1,    y^(0)(0) = 0
x^(1)(0) = 1,    y^(1)(0) = 1
x^(2)(0) = 2,    y^(2)(0) = 5
x^(3)(0) = 4,    y^(3)(0) = 16
x^(4)(0) = 11,   y^(4)(0) = 50
x^(5)(0) = 31,   y^(5)(0) = 151
```

Для ОДУ 2-го порядка `y'' = −4y, y(0)=0, y'(0)=2`:

```
y(t) = 2t − 4/3 · t^3 + 4/15 · t^5
y'(t) = 2 − 4t^2 + 4/3 · t^4
```

## Терминология

| Термин | Значение |
|--------|----------|
| Задача Коши | ОДУ + начальные условия в одной точке |
| Одношаговый метод | Использует только `y_n` для получения `y_{n+1}` |
| Многошаговый метод | Использует `y_n, y_{n−1}, ...` |
| Явный метод | `y_{n+1}` выражается явно |
| Неявный метод | `y_{n+1}` входит в правую часть, нужно решать уравнение |
| Порядок метода | Степень `p` в `O(h^p)` для глобальной погрешности |
| Согласованность | `Σα_i = 0`, `Σβ_i = 1` |
| Устойчивость | Корни характеристического уравнения внутри единичного круга |
| Сходимость | Согласованность + устойчивость |
| PEC | Predictor-Evaluation-Corrector |
| Ряд Маклорена | Ряд Тейлора в точке `t_0 = 0` |
